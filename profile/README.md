## 🎮 What We Do

This organization is home to **Panda Mini Games**, a single Telegram bot that opens a growing collection of games.

Every game runs inside Telegram, supports **English and Persian**, and is built to start in seconds with friends.

Our goal is simple:

> **Open the bot, pick a game, and play together.**

---

## 🚀 Games

### 🕵️ Who's the Spy?

A word game for 4 to 10 friends. Everyone gets a secret word except the spy. Give clues, vote, and find them before they bluff their way through.

Status: 🧪 In Testing

### 🧠 Brain Battle

Quick quiz battles against real players, with ranked matches, leagues, a daily challenge and practice mode.

Status: 🧪 In Testing

## 🧩 How It Is Organized

```yaml
bot:
  - one Telegram bot and game launcher
  - shared language setting
  - shared channel membership

games:
  - one repository per game
  - one Telegram Mini App per game
  - listed in the bot automatically

players:
  - nothing to install
  - English and Persian
  - server-side rules for fair play
```
